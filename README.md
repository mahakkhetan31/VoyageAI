# 🌍 VoyageAI

> AI-powered travel planner that creates personalized itineraries and exports them as beautifully formatted PDFs.


# Overview

VoyageAI is an AI-powered travel planning application that generates customized travel itineraries based on user preferences.

Instead of spending hours researching destinations, hotels, budgets, and attractions, users simply provide their travel details and VoyageAI creates a detailed day-wise itinerary along with a downloadable PDF.

This project is built to demonstrate modern AI application development using LLMs, FastAPI, React, and PDF generation.

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/mahakkhetan31/VoyageAI.git
```

Move into the project

```bash
cd VoyageAI
```

---

## Backend Setup

```bash
cd backend
```

Create virtual environment

```bash
python -m venv venv
```

Activate

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run FastAPI

```bash
uvicorn app.main:app --reload
```

---

## Frontend Setup

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Run

```bash
npm run dev
```
